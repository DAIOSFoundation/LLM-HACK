🧠 모델 역할

각 역할에 쓸 백엔드를 지정합니다. NVIDIA Nemotron·MiniMax·Claude 중 선택. 🤖=피지컬AI 특화(로봇 두뇌). 「타깃 LLM」 = 공격 대상 LLM 에이전트입니다 — 아래 타깃 시스템 프롬프트를 씌워 실제로 공격합니다(공격 타깃=LLM 에이전트일 때). 공격 타깃이 HTTP 엔드포인트면 실물 로봇 API가 대상. 공격자=Claude 는 재밍 페이로드 생성을 거부할 수 있습니다.

➕ LLM 엔드포인트 추가 (타깃 LLM·공격자·판정으로 사용)

OpenAI 호환 엔드포인트(OpenAI·Together·Groq·로컬 Ollama·타 조직 API 등)를 추가하면 위 모델 역할 드롭다운에 즉시 나타납니다. 타깃 LLM에 지정하면 그 모델이 곧 공격 대상이 됩니다. API 키는 서버 메모리에만 유지됩니다.

🎯 공격 타깃 (실제 공격 대상)

둘 다 실제 공격입니다. LLM 에이전트: 위 타깃 LLM(nemotron 등)에 아래 타깃 시스템 프롬프트를 씌워 직접 공격 — NVIDIA 모델 공격이 곧 실전. HTTP 엔드포인트: 아래 값이 실물 로봇 API로 전송(개발자도구 Network에서 제출요청 복사).
URL만 넣고 「자동 설정」 → Claude가 요청/응답 스키마를 추론해 live 반영. 로그인 필요하면 「토큰 획득」.
